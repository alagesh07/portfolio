# Alagesh Venkat K - Portfolio

A clean, professional portfolio website for an IT graduate showcasing skills, projects, and contact information.

## Features

- Responsive design with mobile navigation
- Smooth scrolling and animations (AOS)
- Typing effect for role descriptions
- Skills progress bars
- Resume/CV section
- Contact form
- Social media links

## Setup

1. Add your profile image: `assets/img/profile.jpg`
2. Add your hero background: `assets/img/hero-bg.jpg`
3. Add your resume PDF: `assets/docs/Alagesh_Venkat_Resume.pdf`
4. Update social media links in `index.html`
5. Update phone number in contact section

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Typed.js
- AOS (Animate On Scroll)

## Deployment

You can deploy this portfolio to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting service
